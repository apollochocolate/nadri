나들이 지수는 이렇게 만들어져요

공공데이터포털의 OpenAPI 3종을 조합해, 서버 없이 GitHub만으로 데이터를 모으고 가공해 보여주는 정적 웹앱입니다.

시스템 구조

① 공공데이터포털 API기상청 단기예보 (JSON)
에어코리아 대기오염 (JSON)
관광공사 관광정보 (XML)
→
② GitHub Actions매시간 자동 실행 (cron)
서비스키는 Secrets에 보관
가공 후 data/ 폴더에 커밋
→
③ GitHub Pages정적 JSON·XML 파일 로드
브라우저에서 점수 계산
Chart.js · Leaflet 시각화

브라우저에서 공공데이터 API를 직접 부르면 CORS 정책으로 막히고 서비스키도 노출됩니다. 그래서 수집은 GitHub Actions가 맡고, 웹페이지는 같은 출처의 파일만 읽도록 설계했어요.

나들이 점수 산정 방식

항목가중치계산 기준 (항목별 0~100점)
강수30%100 − 강수확률, 실제 비·눈이 오면 0점
기온25%18~24℃ 만점, 벗어난 1℃마다 −6점
미세먼지25%PM10·PM2.5 중 나쁜 등급 기준 · 좋음 100 / 보통 75 / 나쁨 35 / 매우나쁨 0
하늘10%맑음 100 / 구름많음 75 / 흐림 50
바람10%4m/s 이하 만점, 7m/s까지 60점으로 완만히, 이후 급감

시간마다 점수를 낸 뒤 활동 시간대(9~18시)를 평균해 하루 점수를 만들고, 연속 3시간 평균이 가장 높은 구간을 추천 시간대로 찾습니다(슬라이딩 윈도우). 오늘은 실시간 측정값, 내일부터는 미세먼지 예보 등급을 씁니다.

점수 시뮬레이터 값을 바꿔 보며 알고리즘을 확인해 보세요

적용한 기술

  • GitHub Actions 예약 실행(cron)으로 데이터 자동 수집·커밋
  • JSON(기상·대기) + XML(관광) 두 형식 모두 파싱
  • 위경도 → 기상청 격자 좌표 변환 (Lambert 정각원추도법)
  • 3개 API 조합 + 가중치 기반 점수 알고리즘
  • Promise.all 병렬 로딩, async/await, 오류 처리
  • ES Modules로 브라우저와 Node.js가 같은 코드 공유
  • Chart.js 이중 축 차트 · Leaflet 지도
  • Geolocation API + 하버사인 공식 거리 계산
  • URL 파라미터·localStorage로 페이지 간 상태 유지
  • 날씨에 따라 실내/야외 장소 우선 정렬
  • 검색 디바운스, 반응형 레이아웃
  • 서비스키 Secrets 보관, XSS 방지 이스케이프
